Continuous tree-geometry rethink compact diagnostics
Date: 2026-06-23

Active implementation check:
- Continuous benchmark generators precompute distance_metric=mahalanobis_time.
- Dispatch forwards the precomputed distance for cases with
  requires_precomputed_tbs_distance=True.
- Manuscript representation text currently says explicit continuous benchmark
  cases use precomputed Euclidean distance, which does not match the live code.

Formula implemented for continuous tree distance:

  d(a,b) = (x_a - x_b)^T Sigma_hat^{-1} (x_a - x_b) / p

where Sigma_hat is the shrinkage covariance estimated from the full generated
continuous matrix.

  geometry; they should not be treated as pure gate failures.
