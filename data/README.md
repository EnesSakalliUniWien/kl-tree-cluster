# Data Directory

This directory contains reusable input data, not benchmark run outputs.

- `feature_matrices/`: feature matrices used by scripts and clustering runs.
- `reference/`: external reference tables used for interpretation.
- `CMS_feature_matrices/`: unpacked CMS feature matrix bundle.
- `CMS_*` and `HC_*`: source matrices and short dataset notes for HC/CMS experiments.

Generated clustering outputs that were previously under `data/results_*` now live under `benchmarks/results/02_hc_cms_go_runs/data_alpha_runs/`.
