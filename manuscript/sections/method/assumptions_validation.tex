\subsection{Assumptions, Tuning Parameters, and Validation Status}
\label{sec:assumptions-validation}

The preceding subsections define the implemented algorithm. This subsection
separates mathematical assumptions from implementation choices and records
which parts still require validation before the manuscript can support
submission-level claims.

\paragraph{Statistical assumptions.}
The edge and sibling standardizations use the covariance model declared by the
active feature-space block. Bernoulli blocks use Bernoulli variances, categorical
one-hot blocks use a drop-last multinomial covariance, and continuous blocks use
empirical-Gaussian covariance estimated from descendant leaves. These models are
exact only under their corresponding fixed-membership sampling assumptions and
become approximations for correlated features, high-cardinality one-hot blocks,
finite-sample continuous covariance estimates, discretized benchmark variants,
and data-dependent subtrees. The projected-Wald reference further treats the
selected orthonormal projection rows as fixed when evaluating the projected
quadratic form. This yields a chi-square reference for a fixed subspace under
an isotropic standardized null, but it is not by itself an exact selective
inference result for a hierarchy learned from the same data. Selective
inference after data-dependent hypothesis selection requires conditioning on
the selection event \citep{fithian2014optimal,lee2016exact}; for hierarchical
clustering, this distinction is explicit in selective tests for differences in
cluster means after agglomerative clustering \citep{gao2024selective}.

\paragraph{High-dimensional spectral assumptions.}
The Marchenko--Pastur rule is used as a local signal-dimension heuristic for
correlation-scale spectra. Random-matrix theory gives a useful reference for
noise eigenvalue bulk behavior in high-dimensional settings
\citep{marchenko1967distribution,johnstone2018pca}, but the implementation
applies the rule to local subtree matrices that include both leaf rows and
internal-node distribution rows. Those local matrices are structured,
overlapping summaries rather than independent observations from a classical
spiked covariance model. The MP threshold should therefore be presented as a
dimension-selection rule requiring finite-sample validation, not as a proven
optimal detector in this setting.

\paragraph{Empirical-null inflation assumptions.}
The sibling inflation model assumes that tree-selected sibling statistics
share a context-dependent multiplicative scale distortion. The estimator uses
joint child-edge null-evidence weights, feature-family matching, and a local
context over log sibling projection dimension and, for non-Bernoulli feature
families, log parent size. These choices define a practical calibration model.
They do not estimate posterior null probabilities and do not provide an exact
selective p-value. Their role is to reduce observed anti-conservatism from
reusing the data to construct and test the hierarchy. The open mathematical
object is still the selected-hierarchy law for the selected ratio, not merely a
mean inflation factor.
