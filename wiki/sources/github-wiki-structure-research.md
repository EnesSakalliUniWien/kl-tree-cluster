# GitHub Wiki Structure Research

## Summary

This source records lightweight design references for the local wiki scaffold:
Foam-style wikilinks, GitHub Docs-style frontmatter, markdownlint-style
Markdown checks, and remark link validation as possible future additions.

## Key Points

- The current implementation uses the design ideas but does not add those tools
  as runtime dependencies.
- [[schema]] adopts frontmatter and stable naming conventions.
- [[maintenance]] keeps markdownlint and remark validation as future options
  rather than required checks.
